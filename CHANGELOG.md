# Changelog

## v1.0.0

- Initial public release of the personal VPS management panel.
- Added `config.json` support for bind address, port, filesystem scope, and service limits; restart the panel after editing configuration.
- Uses loopback binding by default and supports custom scope directories with bubblewrap isolation.
- Includes file management, terminal, process/package views, Copilot integration, and configurable MCP connectors.
